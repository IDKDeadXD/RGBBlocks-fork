# RGBBlocks v1.1.9.2
**Fork updated for Minecraft 1.21.1 NeoForge**

## Added
- **Paint Bucket** tooltip now always shows the color hex code
- **Paint Bucket** tooltip now tells you to sneak-use on an RGB block to copy its color
- Hue, saturation and brightness values now show in advanced tooltips (F3+H)
- RGB blocks now accept colors set via commands using hex strings, `rgb` arrays, or `red`/`green`/`blue` values

## Fixed
- Fixed issue with **RGB blocks** rendering black or with the wrong color when placed
- Fixed a bug where **RGB blocks** were not updating their color for other players
- Fixed issue with **Paint Bucket** color not being saved correctly
- Fixed issue with **RGB blocks** losing their color after falling or being dispensed
- Fixed a bug where **RGB concrete powder** was showing the wrong color
- Fixed issue with **Framed Blocks** camo not keeping the correct color
- Fixed issue with **The One Probe** showing the wrong hex code
- Fixed a bug where opening the **Paint Bucket** color picker could crash on servers
- Fixed issue with **Paint Bucket** crafting not matching block colors correctly
- Fixed issue with **Iris** and other rendering mods causing block color issues
